# Соглашения кода, CSS и токены

Чек-лист собран из замечаний ревьюеров в PR этого репозитория (2022–2026) и из `docs/development-faq.stories.mdx`. Текст в кавычках-«ёлочках» — формулировки из этих замечаний.

**Все правила ниже — про новый и изменённый код.** В репозитории много старого кода, который им не соответствует: `type` вместо `interface`, буквенные размеры, файлы в camelCase, узлы без `dataTestId`. Несоответствие в строках, которые PR не трогает, — не finding.

## Типы и именование

- **Новые типы props — `interface`, не `type`** (#1965, #1975). Пример «Good» в `docs/development-faq.stories.mdx` с `type InputProps` устарел и в этой части.
- **Венгерская нотация не используется:** никаких `IProps`, `TProps`, `sBackground` — «мы не используем венгерскую нотацию».
- **Обработчики событий внутри компонента — `handleSomethingClick`**, не `onSomethingClick` (`docs/development-faq.stories.mdx`). Callback'и наружу — сигнатура `(event, payload) => void` (там же).
- **Размеры — числовые** (`size?: 32 | 40 | 48 | 56 | 64 | 72` в `packages/button/src/typings.ts`). Для компонентов, где числовые размеры уже есть, буквенные — deprecated: «ставь по возможности числовые размеры, буквенные уже deprecated» (#1568). У компонентов, где есть только буквенный `size` (например, `Tabs`), это не finding. Примеры с буквенными размерами в `docs/development-faq.stories.mdx` устарели — не ссылайся на них как на образец.
- **Новые папки и файлы утилит — kebab-case** (`human-file-size.ts`, не `humanFileSize.ts`, #1823). ESLint это не проверяет (`unicorn/filename-case` и `dirnames/match-kebab-case` отключены в `.eslintrc.cjs`), проверка ручная. Файлы самого компонента называются по образцу пакета: `Component.tsx`, `typings.ts` или `types.ts` — как уже принято в пакете, `index.module.css`.

## Структура компонента

- **`dataTestId`** прокидывается в `data-test-id` корневого элемента; для вложенных элементов — `getDataTestId` из `@alfalab/core-components-shared`. Новый компонент или новый **смысловой** вложенный узел без этого — finding. Смысловой — тот, который потребитель ищет в тестах (шапка, контент, футер, кнопка). Служебные узлы — невидимые измерительные `div`, обёртки, маркеры — идентификатора не требуют: у самих компонентов библиотеки их тоже нет.
- **`displayName` — у новых компонентов, обёрнутых в `forwardRef`:** без него React DevTools показывает компонент без имени. Требуется только для нового компонента; отсутствие у существующих — не finding. В остальных случаях `displayName` не нужен, и его отсутствие — не finding.
- **`index.ts` не экспортирует лишнее:** тип или утилита, нужные только внутри пакета, наружу не отдаются — всё экспортированное становится публичным контрактом (и помни про `shared/index.ts` — см. `references/public-api.md`).
- **Desktop-, mobile- и responsive-реализации одного компонента меняются согласованно.** Правка поведения только в одной из них — finding, если различие не объяснено платформой.
- **Не дублировать то, что уже есть** в `@alfalab/core-components-shared`, `@alfalab/core-components-mq`, `@alfalab/hooks` и утилитах пакета: прежде чем принять новый хелпер или хук, поищи готовый.
- **Чинить надо в том пакете, где причина.** Заплатка в вышестоящем пакете вместо исправления причины — finding.

## CSS и токены

- **Вместо захардкоженных цветов, отступов и радиусов — токены:** числовые `--gap-*` (`--gap-8`, `--gap-16`; буквенные `--gap-s`, `--gap-m` — deprecated, `packages/vars/src/gaps.css`), `--color-*`, числовые `--border-radius-*` (`packages/vars/src/border-radius.css`), а также готовые наборы вроде `safe-area.css` (`--sat`, `--sab` поверх `env(safe-area-inset-*)`) и миксины из `mixins.css`.
- **Новую CSS-переменную компонента заводи, если значение должны переопределять темы.** Переменная в `:root` видна потребителям, они могут начать её переопределять — и её удаление станет мажорным изменением (см. `references/public-api.md`).
- **Объявления переменных — в `:root`.** Правило может быть пересмотрено: открыт issue #1569 о том, что переменные компонентов в `:root` замедляют DevTools.
- **Нейминг переменных:** единое соглашение пока не принято. Модификатор (например, `inverted`) встречается в разных частях имени — и в середине (`--action-button-inverted-disabled-bg-color`), и в конце; оба варианта допустимы. Порядок частей в имени переменной — не finding.
- **Правила внутри медиазапроса не выносят наружу.** Правка «для PWA» (`@media (display-mode: standalone)`) или для конкретного брейкпоинта, перенесённая за пределы своего медиазапроса, меняет поведение для всех остальных случаев.

## Severity

| Ситуация                                                                                                          | Severity                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Поведение изменено только в одной из desktop/mobile-реализаций без объяснения                                     | **P2**                                                                                                       |
| Заплатка в вышестоящем пакете вместо исправления в пакете-причине                                                 | **P2**                                                                                                       |
| Новый хелпер или хук дублирует готовый из `shared`, `mq` или `@alfalab/hooks`                                     | **P2**                                                                                                       |
| Новая CSS-переменная для внутренней реализации, а не для темизации                                                | **P3**                                                                                                       |
| Захардкоженное значение там, где есть готовый токен                                                               | **P2** (не следует за темой и обновлениями дизайн-системы — у части потребителей будет визуальная регрессия) |
| Нет `dataTestId` у нового компонента или нового смыслового узла                                                   | **P3**                                                                                                       |
| Правило из медиазапроса вынесено за его пределы                                                                   | **P2**                                                                                                       |
| Из `index.ts` экспортируется тип или утилита, нужные только внутри пакета                                         | **P2** (после релиза убрать экспорт можно будет только мажором)                                              |
| Оформление: `type` вместо `interface`, венгерская нотация, имя обработчика, буквенный размер, регистр имени файла | **P3**                                                                                                       |
| То же самое в коде, который PR не трогает                                                                         | не finding                                                                                                   |
