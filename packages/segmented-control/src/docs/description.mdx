## Размеры и стили

Для контрола доступно два размера и два вида скруглений.

```jsx live
render(() => {
    const [selectedId, setSelectedId] = React.useState({
        '1': 1,
        '2': 1,
        '3': 1,
        '4': 1,
    });
    const handleChange = (pos, id) => setSelectedId({ ...selectedId, [pos]: id });
    return (
        <div style={{ width: 360 }}>
        <Space fullWidth size={24}>
            <SegmentedControl size={40} onChange={(id) => handleChange('1', id)} selectedId={selectedId["1"]}>
                <Segment id={1} title='Таб 1' />
                <Segment id={2} title='Таб 2' />
            </SegmentedControl>
            <SegmentedControl onChange={(id) => handleChange('2', id)} selectedId={selectedId["2"]}>
                <Segment id={1} title='Таб 1' />
                <Segment id={2} title='Таб 2' />
            </SegmentedControl>
            <SegmentedControl size={40} shape='rounded' onChange={(id) => handleChange('3', id)} selectedId={selectedId["3"]}>
                <Segment id={1} title='Таб 1' />
                <Segment id={2} title='Таб 2' />
            </SegmentedControl>
            <SegmentedControl shape='rounded' onChange={(id) => handleChange('4', id)} selectedId={selectedId["4"]}>
                <Segment id={1} title='Таб 1' />
                <Segment id={2} title='Таб 2' />
            </SegmentedControl>
        </Space>
    </div>
    )
})
```

## Ширина сегментов

По умолчанию (`segmentWidth='equal'`) сегменты одинаковой ширины и вместе занимают весь контейнер. В режиме `segmentWidth='content'` ширина сегментов подстраивается под контент.

```jsx live
render(() => {
    const [selectedId, setSelectedId] = React.useState({
        '1': 1,
        '2': 1,
    });
    const handleChange = (pos, id) => setSelectedId({ ...selectedId, [pos]: id });
    return (
        <div style={{ width: 360 }}>
        <Space fullWidth size={24}>
            <SegmentedControl selectedId={selectedId["1"]} onChange={(id) => handleChange('1', id)}>
                <Segment id={1} title='Таб' />
                <Segment id={2} title='Длинный таб' />
                <Segment id={3} title='Таб 3' />
            </SegmentedControl>
            <SegmentedControl segmentWidth='content' selectedId={selectedId["2"]} onChange={(id) => handleChange('2', id)}>
                <Segment id={1} title='Таб' />
                <Segment id={2} title='Длинный таб' />
                <Segment id={3} title='Таб 3' />
            </SegmentedControl>
        </Space>
    </div>
    )
})
```

## Аддоны

Слева и справа от заголовка сегмента можно разместить дополнительный элемент. Размер слота — 20px для размера 32, 24px для размеров 40 и 48.

```jsx live

    const [selectedId, setSelectedId] = React.useState({
        '1': 1,
        '2': 1,
        '3': 1,
        '4': 1,
        '5': 1,
        '6': 1,
        '7': 1,
        '8': 1,
        '9': 1,
    });
    const handleChange = (pos, id) => setSelectedId({ ...selectedId, [pos]: id });
    const diamonds20 = { content: <Diamonds20Icon /> };
    const diamonds24 = { content: <Diamonds24Icon /> };
    return (
        <div style={{ width: 360 }}>
        <Space fullWidth size={24}>
            <Space fullWidth size={12}>
                <Typography.Text view='primary-medium' weight='bold'>Слева, справа и с обеих сторон</Typography.Text>
                <SegmentedControl size={32} selectedId={selectedId['1']} onChange={(id) => handleChange('1', id)}>
                    <Segment id={1} title='Таб 1' addons={{ left: diamonds20 }} />
                    <Segment id={2} title='Таб 2' addons={{ left: diamonds20 }} />
                </SegmentedControl>
                <SegmentedControl size={40} selectedId={selectedId['2']} onChange={(id) => handleChange('2', id)}>
                    <Segment id={1} title='Таб 1' addons={{ right: diamonds24 }} />
                    <Segment id={2} title='Таб 2' addons={{ right: diamonds24 }} />
                </SegmentedControl>
                <SegmentedControl size={48} selectedId={selectedId['3']} onChange={(id) => handleChange('3', id)}>
                    <Segment id={1} title='Таб 1' addons={{ left: diamonds24, right: diamonds24 }} />
                    <Segment id={2} title='Таб 2' addons={{ left: diamonds24, right: diamonds24 }} />
                </SegmentedControl>
            </Space>
            <Space fullWidth size={12}>
                <Typography.Text view='primary-medium' weight='bold'>Ширина по контенту</Typography.Text>
                <SegmentedControl size={32} segmentWidth='content' selectedId={selectedId['4']} onChange={(id) => handleChange('4', id)}>
                    <Segment id={1} title='Таб' addons={{ left: diamonds20 }} />
                    <Segment id={2} title='Длинный таб' addons={{ left: diamonds20 }} />
                    <Segment id={3} title='Таб 3' />
                </SegmentedControl>
                <SegmentedControl size={40} segmentWidth='content' selectedId={selectedId['5']} onChange={(id) => handleChange('5', id)}>
                    <Segment id={1} title='Таб' addons={{ left: diamonds24 }} />
                    <Segment id={2} title='Длинный таб' addons={{ left: diamonds24 }} />

                <Typography.Text view='primary-medium' weight='bold'>Только аддон</Typography.Text>
                <SegmentedControl size={32} segmentWidth='content' shape='rounded' selectedId={selectedId['7']} onChange={(id) => handleChange('7', id)}>
                    <Segment id={1} addons={{ left: diamonds20 }} />
                    <Segment id={2} addons={{ left: diamonds20 }} />
                    <Segment id={3} addons={{ left: diamonds20 }} />
                </SegmentedControl>
                <SegmentedControl size={40} segmentWidth='content' shape='rounded' selectedId={selectedId['8']} onChange={(id) => handleChange('8', id)}>
                    <Segment id={1} addons={{ left: diamonds24 }} />
                    <Segment id={2} addons={{ left: diamonds24 }} />

                    <Segment id={2} addons={{ left: diamonds24 }} />
```
