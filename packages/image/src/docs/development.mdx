## Подключение

```jsx
import { Image } from '@alfalab/core-components/image';
```

## Глобальные настройки

Дефолты (`proxyMap`, `inViewOption`) можно задать через `CoreConfigContext`, чтобы не прокидывать их в каждый вызов:

```jsx
import { CoreConfigContext } from '@alfalab/core-components-config';

<CoreConfigContext.Provider
    value={{
        breakpoint: 1024,
        client: 'desktop',
        components: {
            Image: {
                inViewOption: true,
                proxyMap: [
                    {
                        from: 'https://web.alfabank.ru/mobile',
                        to: 'https://alfaonline.servicecdn.ru/public',
                    },
                ],
            },
        },
    }}
>
    <App />
</CoreConfigContext.Provider>
```

Пропсы `proxyMap` и `inViewOption` на самом `Image` перекрывают значения из контекста.

## Retry

Если URL после `proxyMap` (CDN) не загрузился, компонент один раз откатывается на исходный `src`.
