## Картинка с фиксированной высотой

```jsx live mobileWidth={560} mobileOnly
render(() => {
    const [open, setOpen] = React.useState(false);

    return (
        <React.Fragment>
            <Button onClick={() => setOpen((prev) => !prev)}>Показать модалку</Button>
            <UniversalModalMobile open={open} onClose={() => setOpen(false)}>
                <UniversalModalMobile.Header
                    headerMode='relative'
                    hasBackButton={true}
                    hasCloser={true}
                    title='Title'
                    bottomAddons={
                        <ButtonMobile view='primary' block={true}>
                            Bottom
                        </ButtonMobile>
                    }
                    image={{
                        src: './images/universal-modal_header-image.png',
                        height: 160,
                    }}
                    onBack={() => setOpen(false)}
                />
                <UniversalModal.Content>
                    <Typography.Text tag='p'>
                        Шапка сохраняет высоту 160px: при изменении ширины экрана высота не
                        меняется, картинка заполняет шапку целиком и обрезается по краям.
                    </Typography.Text>
                </UniversalModal.Content>
            </UniversalModalMobile>
        </React.Fragment>
    );
});
```
