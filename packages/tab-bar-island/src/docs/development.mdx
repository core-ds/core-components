## dark.css

`TabBarIsland` использует кастомный маппинг цветовых токенов `light/dark`. Поэтому для корректной работы `dark.css` из `themes` необходимо дополнительно подключить:

```css
@import '@alfalab/core-components-tab-bar-island/dark.css';
```
