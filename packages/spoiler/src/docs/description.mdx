## Поведение

Spoiler скрывает баланс или другую чувствительную информацию за облаком частиц.
При скрытии контента плавно появляются движущиеся точки, а при раскрытии облако исчезает,
показывая актуальное значение.

При наведении мыши ближайшие точки мягко отталкиваются от курсора и возвращаются после его
ухода. Наведение не раскрывает содержимое. Эффект одинаково работает с текстом и изображениями.
Отключить реакцию на курсор можно через `interactiveParticles={false}`.
При системной настройке «Уменьшить движение» оба направления переключения происходят мгновенно.

```jsx live
render(() => {
    const [open, setOpen] = React.useState(true);
    const [interactiveParticles, setInteractiveParticles] = React.useState(true);
    const [valueIndex, setValueIndex] = React.useState(0);
    const values = ['−4 940 ₽', '−5 186 ₽'];

    React.useEffect(() => {
        if (open) return undefined;

        const timer = window.setTimeout(() => {
            setValueIndex((current) => (current + 1) % 2);
        }, 500);

        return () => window.clearTimeout(timer);
    }, [open]);

    return (
        <>
            <Typography.Title tag='div' view='medium' font='system'>
                <Spoiler
                    open={open}
                    onOpenChange={setOpen}
                    interactiveParticles={interactiveParticles}
                >
                    {values[valueIndex]}
                </Spoiler>
            </Typography.Title>
            <Gap size={24} />
            <Switch
                checked={!open}
                label='Скрыть'
                onChange={() => setOpen((current) => !current)}
            />
            <Gap size={16} />
            <Switch
                checked={interactiveParticles}
                label='Реакция на курсор'
                onChange={() => setInteractiveParticles((current) => !current)}
            />
        </>
    );
});
```

## Использование с текстом

Компонент размещается внутри `Typography.Text` или `Typography.Title` и наследует типографику.
Спойлер можно поставить внутри текстового слоя: частицы повторяют строки и сохраняют переносы.
Вложенное выделение текста также поддерживается.

```jsx live
render(() => {
    const [open, setOpen] = React.useState(false);

    return (
        <div style={{ maxWidth: 360 }}>
            <Typography.Text view='primary-medium'>
                Доставка ожидается{' '}
                <Spoiler open={open} onOpenChange={setOpen}>
                    <strong>в пятницу после 18:00</strong>, по адресу: улица Лесная, дом 12.
                </Spoiler>{' '}
                Мы заранее отправим уведомление.
            </Typography.Text>
            <Gap size={24} />
            <Switch checked={!open} label='Скрыть' onChange={() => setOpen((value) => !value)} />
        </div>
    );
});
```

## Использование с другими элементами

В `mode='element'` частицы закрывают всю площадь контейнера с изображением или любым другим
контентом, сохраняя исходные размеры элемента при скрытии и раскрытии.

```jsx live
render(() => {
    const [open, setOpen] = React.useState(false);

    return (
        <>
            <Spoiler
                mode='element'
                open={open}
                onOpenChange={setOpen}
                style={{ borderRadius: 'var(--border-radius-8)' }}
            >
                <img
                    src='./images/gorgeous-garden.png'
                    alt='Пейзаж'
                    width={150}
                    height={150}
                    style={{ display: 'block', objectFit: 'cover' }}
                />
            </Spoiler>
            <Gap size={24} />
            <Switch checked={!open} label='Скрыть' onChange={() => setOpen((value) => !value)} />
        </>
    );
});
```

### Вложенная кнопка

Кнопка внутри раскрытого спойлера работает самостоятельно и не скрывает содержимое.
Для проверки с клавиатуры нажмите Tab до спойлера, затем Enter для раскрытия:
следующий Tab перейдёт к кнопке «Действие», затем — к кнопке «После спойлера».
